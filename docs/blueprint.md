# **App Name**: Aaromach Command Center

## Core Features:

- Secure Multi-Role Authentication: Robust authentication system using Firebase Authentication with email/password and Firebase Custom Claims for role-based access (Admin, Technician, Client), ensuring secure portal entry.
- Role-Specific Operations Dashboard: Dynamic dashboards providing personalized key performance indicators, critical alerts (e.g., unassigned jobs, late check-ins), and active assignments relevant to each user's role.
- Dynamic Assignment & Work Order Management: Comprehensive functionality for administrators to create, assign, and track work orders and projects, while technicians manage their scheduled tasks and clients monitor project progress and daily logs.
- AI-powered Assignment Recommendation Tool: An intelligent tool for administrators that provides optimal technician assignment recommendations based on factors such as current location, reliability score, and existing workload, drawing insights from past data.
- Time Logging & GPS Verification: Technicians can accurately log work hours with integrated GPS check-in/out functionality, capturing location data for verifying on-site activity and ensuring compliance.
- Financial Tracking & Weekly Manifest Processing: A streamlined process for technicians to submit weekly manifests detailing work outcomes and for administrators to review, approve, manage payroll calculations, and track reimbursements.
- Client Service Request & Status Tracking: A dedicated portal enabling clients to easily submit new service requests, attach relevant details, and track the real-time status and progression of their requests and active projects.

## Style Guidelines:

- Primary action color: A vibrant, impactful red (#D82D2D) to signify alerts, critical information, and primary call-to-actions, evoking a command center's urgency and importance.
- Background color: A deep, subtly warm charcoal (#241F1F), providing a high-contrast foundation that is reminiscent of technical monitoring screens and dark-mode operational interfaces.
- Accent color: An energetic, rich gold (#DAA520) for interactive elements, successful status indicators, and to draw attention to secondary actions, creating dynamic visual interest on the dark background.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-oriented, and commanding presence in titles and section headers.
- Body font: 'Inter' (sans-serif) for its neutrality, readability, and clean appearance, ideal for presenting data and operational details clearly across the application.
- Utilize clean, concise line icons or flat filled icons that are easily discernible within a data-rich environment, aligning with the precision and functional aesthetic of a command center.
- Implement a modular and data-dense layout, utilizing card-based designs and clear separation of information blocks to maintain organization and readability on operations overview dashboards.
- Incorporate subtle, quick animations for state changes, data updates, and navigation transitions, ensuring a responsive and modern feel without distracting from critical operational data.
